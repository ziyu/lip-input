# Lip Input

Android-first multilingual visual speech input prototype.

## Development status

Initial development is in progress. This repository does not yet contain a working application or verified speech-recognition model.

## Goals

- Capture silent video on Android without requiring microphone access.
- Recognize visual speech with explicit language selection and model capability reporting.
- Let the user review and edit text before copying or sharing it.
- Keep model licensing, real inference validation, and device performance limitations explicit.

Model weights and credentials must not be committed. Research-only checkpoints must not be described as commercially licensed.
